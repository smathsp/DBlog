# 小龙虾点瑞幸咖啡

## 第一步：打开瑞幸开放平台

- 方式一：浏览器搜索"瑞幸开放平台"
- 方式二：直接打开链接 https://open.lkcoffee.com/

## 第二步：登录账号

1. 网页上点击右上角"登录"按钮
2. 输入你的瑞幸账号手机号
3. 点击"获取验证码"
4. 输入收到的短信验证码
5. 完成登录

## 第三步：获取配置

1. 登录成功后，进入 AI 控制台
2. 找到"Token"区域，点击"创建或者查看 Token"
3. 找到"复制 MCP 配置 JSON"按钮，点击复制

## 第四步：小龙虾自己配置

1. 把刚才复制的内容直接发送给小龙虾，注意不要发送给其他人
2. 根据小龙虾的提示，完成配置

## 第五步：点单

1. 你可以直接跟他说你想喝什么，也可以问他有什么推荐的
2. 记得确认门店地址是不是最近的
3. 确认好后直接扫码支付就能下单
4. 不想要的话记得尽快说取消订单
